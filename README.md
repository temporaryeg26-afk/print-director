# TEMPORARY™ Print Director

Standalone print-preparation tool for TEMPORARY™ — runs entirely in the browser (no AI, no API, works offline once loaded).

- **Director** – checks a design across all products and colors, with per-card recommendations and fixes.
- **Print Lab** – manual control of size, halftone dots, contrast, knockout, distress and embroidery preview.
- **Export** – transparent 300 DPI PNGs at exact print size, deduplicated, as a ZIP.
- **Compare, Test Log, Rules & Knowledge, Guide.**

Live: https://temporaryeg26-afk.github.io/print-director/

To add mockups or designs, drop PNGs into `mockups/` or `designs/` (or upload designs inside the app).
